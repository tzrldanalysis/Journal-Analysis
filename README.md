# Journal Analysis

Daily financial intelligence briefs and reports generated from newspaper editions (WSJ, FT, NYT).

## Structure

```
daily-briefs/
  YYYY/
    MM/
      YYYY-MM-DD-[pub]-brief.md
      YYYY-MM-DD-[pub]-report.md
```

- **Brief**: concise thematic summary (~800-900 words)
- **Report**: detailed multi-section analysis (themes, company intelligence, sentiment, risks/opportunities, ETF/stock picks, research call questions)

Generated automatically each weekday morning from the incoming PDF edition.
